# Support

MediaPicker is an early-development Swift package. Its public API and behavior
may change before `1.0.0`, and only the latest development revision is currently
supported.

## Getting help

Before opening an issue:

1. Read the [README](README.md), [roadmap](Docs/Roadmapv0.0.1.md), and
   [contribution guide](CONTRIBUTING.md).
2. Search existing issues for the same behavior or request.
3. Reproduce the problem with the latest revision when possible.

Use the repository's bug-report template for reproducible incorrect behavior
and the feature-request template for proposed capabilities. Include the
MediaPicker revision, iOS version, Xcode and Swift versions, device or simulator,
the smallest reproduction, and sanitized diagnostics.

Support is provided on a best-effort basis. Response or resolution times are
not guaranteed, and questions outside MediaPicker's documented scope may be
closed or redirected.

## Security reports

Do not use a public issue for a suspected vulnerability. Follow the private
reporting process in [SECURITY.md](SECURITY.md).
